# React + Vite (Front End) + Flask (Back End)
If you want to run this website locally you need to install npm, npx, pip, and python. Once installed run the Backend python file (python app.py OR py app.py) and run the Frontend (npm run dev)

# Project Goals:
**Functioning Team Website that effectively showcases Paragon Robotics**


# How to Run

We reccomend running with `bun` as opposed to  `npm`.

**Frontend**:

`bun install`

`bun run dev`

**Backend**

`pip install flask && flask_cors`

`python app.py`
