# Svelte + Vite (Front End)
If you want to run this website locally you need to install npm, npx, bun (optionally), and run the Frontend (npm run dev)

# Project Goals:
**Functioning Team Website that effectively showcases Paragon Robotics**


# How to Run

We reccomend running with `bun` as opposed to  `npm`.

**Frontend**:

`bun install`

`bun run dev`
